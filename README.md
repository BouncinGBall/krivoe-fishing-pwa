# Клёв рядом — бесплатное PWA для рыбалки

Статическое мобильное приложение для Safari на iPhone: офлайн-схема Кривого озера, Уловного озера и Суходольского озера с участком реки Бурная, модельными глубинами, режимом «3D рельеф», перспективными зонами, погодой, объяснимым индексом клёва, сравнением водоёмов и локальным журналом.

Это бесплатный PWA-прототип без сборщика, npm и платной публикации в App Store. В приложении нет аналитики и аккаунтов: журнал хранится только в `localStorage` браузера.

## Установка на iPhone

PWA и Service Worker требуют HTTPS (исключение — `localhost` на компьютере). Самый простой бесплатный путь:

### GitHub Pages

1. Создайте бесплатный репозиторий на GitHub.
2. Загрузите **содержимое этой папки** (`index.html`, `app.js`, `data.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg`) в корень ветки `main`.
3. Откройте `Settings → Pages`, выберите `Deploy from a branch → main → /(root)` и сохраните.
4. После публикации откройте выданный адрес `https://…github.io/…/` в Safari.
5. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Cloudflare Pages и любой другой статический HTTPS-хостинг работают так же: загрузите папку без изменения структуры. Платный Apple Developer и App Store для этой версии не нужны.

Перед поездкой один раз откройте приложение онлайн, выберите каждый из трёх водоёмов и нажмите «Обновить прогноз». Тогда приложение закэширует оболочку, схему и последний прогноз. После этого карта, глубины, зоны и журнал доступны без сети; погода обновляется при следующем подключении. Кнопка «Спутник» открывает внешний Google Maps и поэтому требует интернет.

Для локальной проверки на компьютере:

```text
python -m http.server 8000
```

Запускайте команду из этой папки и откройте `http://localhost:8000` в браузере. Адрес `file://…` не подходит для проверки Service Worker.

## Возможности

- переключение Кривого, Уловного и Суходольского озёр;
- офлайн-контуры берегов, 2D-модель глубин и наклонённый режим «3D» без внешних тайлов;
- модельные «перспективные зоны» с глубиной, целевой рыбой, причиной и динамическим баллом;
- участок Бурной на схеме Суходольского и предупреждение о течении/правилах;
- текущая и почасовая погода Open-Meteo, три лучших окна для выхода и сравнение водоёмов;
- целевая рыба: универсально, щука, окунь, плотва/лещ, налим;
- геолокация, копирование координат выбранного водоёма и внешний спутниковый просмотр;
- локальный журнал промеров, уловов и точек с экспортом JSON/CSV.

| Уловное озеро (Rautjärvi) | `60.59290325899254, 30.208761245012283` | протока, окунёвая бровка, выход к Волчьей |
| Суходольское озеро (Суванто) | ориентир OSM в данных приложения | устье Лосевской протоки, свал, отмели у Зелёного мыса |
| р. Бурная | участок у восточной части Суходольского | линия течения; правила и лицензии проверяются отдельно |

Кнопка «коорд.» внизу карты копирует координату водоёма в формате `широта, долгота`, чтобы вставить её в навигатор. Для открытия формы новой записи приложение использует ближайшую точку обзора внутри контура.

## Источники, допущения и точность

- Контуры береговой линии: OpenStreetMap, производное упрощение для мобильной загрузки, лицензия ODbL; атрибуция показана под картой и в разделе «Данные».
- Схемы глубин: FishingPiter, карты 64 (Кривое), 172 (Уловное) и 147 (Суходольское).
- Уловное: вспомогательная оценка GLOBathy. Для Суходольского противоречивое значение GLOBathy около 62 м намеренно не используется; в приложении оставлен опубликованный максимум 24 м.
- Погода: Open-Meteo, текущие и почасовые поля, часовой пояс Europe/Moscow, кэшируется локально.
- ICESat-2 не выдаёт готовую сплошную батиметрию дна этих небольших озёр. Поэтому заливки глубин — сочетание опубликованных схем, контура и эвристической интерполяции. Все глубины помечены как модельные/ориентировочные и не заменяют эхолот или навигационный прибор.
- «Жорные зоны» — гипотезы по свалам, мелководью, протокам и описаниям источников. Они не являются гарантией клёва.
- «LIVE» означает текущую погоду и пересчёт модели. Потока реальных уловов, рыбаков или датчиков в реальном времени в этой версии нет.
- Полевые промеры и уловы сохраняются на устройстве: уловы дают небольшой калибрующий бонус, промеры повышают показатель уверенности. Это не замена измерениям эхолотом.
- Для Бурной перед рыбалкой проверьте действующие правила, лицензии, сезонные запреты и безопасность течения. На лёд выходите только после личной проверки толщины и состояния.

## Формула индекса

Индекс ограничен диапазоном 8–94 внутри шкалы 0–100 и складывается из:

- суточного окна, привязанного к рассвету и закату Open-Meteo;
- лунного ритма;
- ветра, давления и трёхчасового тренда давления;
- вероятности осадков, облачности и температуры;
- выбранной рыбы, типа перспективной зоны и водоёма;
- локального сигнала уловов (до `+8` баллов).

Рядом с баллом отдельно показывается уверенность: сеть, качество исходной глубинной схемы и количество ваших записей. Высокий балл с низкой уверенностью — повод сначала проверить место.

## Файлы

- `index.html`, `styles.css`, `app.js`, `data.js` — интерфейс и логика без сборки;
- `manifest.webmanifest`, `sw.js` — установка и офлайн-кэш;
- `icon.svg`, `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки для Safari/PWA;
- журнал экспортируется кнопками в JSON или CSV.

Для следующей итерации точности можно добавить импорт треков эхолота/Deeper, ручные промеры с GPS и калибровку зон по реальным уловам.
